## How to read

Each finding has an ID, the component(s) affected, the current state, the consequence, the status,
and the next step. Findings are grouped:

- **DF-xx** — Data findings (extends `docs/data-gaps.md` DG-01…DG-19)
- **SF-xx** — Signal / model / decision-layer findings
- **UF-xx** — User-facing / distribution findings
- **OP-xx** — Operational / infrastructure findings
- **KE-xx** — Strengths to keep (do not change)

"High" value = prevents wrong results, unlocks trust/validation, or affects a large share of the
universe. "Medium" = adds a plausible signal or useful context. "Low" = descriptive or nice-to-have.
Effort: S ≤ 1 day · M a few days · L a week or more.

The single cross-cutting rule: **no new signal enters the composite without an EV-0 pass (ADR 0018)**.
Run the validation loop (Session 1, below) before any re-weighting.

## Best value data to show users (what to surface, where)

### Telegram — the daily touchpoint (keep to one screen per message)

1. **Shortlist with "why"** — top 5–10 by composite, each with sector, one-line driver (e.g., "Value 0.92 · 12m momentum +31% · fair value +14%"), confidence badge, and eligibility. (SF-09, UF-03)
2. **Scorecard first** — the system's own track record (30/91/182d hit rate, avg forward return vs benchmark) *before* the picks, so users calibrate trust. (SF-10, UF-05)
3. **Regime light** — breadth / trend / momentum traffic light per market (already built) — tells users whether to be aggressive this month.
4. **Sectors** — median P/E/P/B + median fair-value gap per sector (`/sectors`) — shows where value is, not just which stocks.
5. **Watchlist P&L** — per-user, per-currency, today + YTD (already built).
6. **Earnings this week** — watchlist + top-25 (already built) — long-term investors care about earnings dates.
7. **Stale feeds** — transparency: if a feed is stale, scores may be off (already in digest).

### Web / marketview — deeper research

1. **Screener explorer** — full universe table, sortable by any factor, with data-completeness badge per stock (coverage %).
2. **Stock dossier** — price chart vs sector, valuation panel (10 methods), sector lens ("what matters in this sector"), news block, score history.
3. **Comparison** — two stocks side by side (fundamentals + valuation methods).
4. **Backtest viewer** — how the screen (or a custom factor combo) did over 5/10 years, with drawdown.
5. **Portfolio view** — user watchlist aggregated, sector weights, dividend income estimate.

### Daily report (`stock_reports`, already generated)

Add to each per-stock markdown report:
- "Drivers of this week's rank" — delta vs previous run (what moved the composite).
- "Last time this screen was this cheap/expensive" — historical percentile of composite.
- Keep the "not investment advice" disclaimer and the ADR 0026 valuation label.

## 8. Follow-Up Changes & Architectural Decisions (2026-11-08, ADR 0033)

All code-actionable data gaps, signal gaps, Telegram AI/routing enhancements, classification soundness fixes, and continuous validation tooling identified during the 2026-11-07/08 review have been implemented and verified:

1. **Data & Signal Gaps Closed:**
   - **DG-07 (`stock_metrics.py`):** Switched daily return/volatility/SMA/drawdown calculations from raw `close` to `COALESCE(adj_close, close)` so splits and dividends no longer distort momentum or low-volatility inputs.
   - **DG-11 (`stock_fundamentals.py`):** Added `COGS_TAGS` (`CostOfGoodsAndServicesSold`, `CostOfRevenue`, `CostOfSales`) and derived `gross_profit = total_revenue - COGS` when direct `GrossProfit` XBRL tags are absent, enabling Novy-Marx gross profitability (`GP/A`) across SEC filers.
   - **SF-05 (`stock_screener.py`):** Implemented `eps_accel` (YoY EPS growth acceleration from the 3 latest annual EPS filings) as the third sub-signal in `growth_score`.
   - **DG-04 (`accuracy_check.py`):** Added `per_stock_second_source()` optional Tiingo EOD cross-check (activates automatically when `TIINGO_API_KEY` is present; skips cleanly otherwise).
2. **Telegram Deterministic-First Cross-Command Routing & Fact-Checked AI Layer (`manifests/telegram/`):**
   - Enabled `DIGEST_NARRATIVE: "1"` on `deployment/telegram-bot` and surfaced verified `per_symbol` (ML-7b) and `event_brief` (ML-7c) narratives in `/stock` and `/news`.
   - Expanded `ask.py` with `screener_facts`, `sector_facts`, `regime_facts`, `scorecard_facts`, `earnings_facts`, enriched `stock_facts`, and `summarize_card` (appends a `factcheck.py`-verified AI takeaway when any command is invoked with `ai` / `explain` / `why` / `?`).
   - Made `add` optional in `/watch <company>` (preserving multi-word notes) and added deterministic-first cross-command routing (`router.fuzzy_command`, `cmd_stock` ↔ `cmd_index` redirect, mismatched command fallback, and `router.ai_route` fallback) with user-visible `↪️` redirection notices.
